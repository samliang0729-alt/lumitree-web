# LumiTree 靈光樹心智圖工作室 — GitHub Pages 版

心智圖編輯與管理工具，協助使用者整理想法、規劃專案、拆解工作及分析問題。介面採淺色系，提供管理首頁、上方工具列、中央編輯畫布及右側設定區，並以不同色塊區分主題階層。

- **目前產品版本**：`v2.0`，以 `index.html` 顯示的版本為準。
- **本版分支**：`main`，網站由 GitHub Pages 發布。
- **網站入口**：[開啟 LumiTree 心智圖工作室](https://samliang0729-alt.github.io/lumitree-web/)。
- **使用方式**：免註冊、免登入，使用瀏覽器即可編輯。
- **資料儲存**：自動儲存在目前瀏覽器的本機工作空間，未提供跨裝置同步。
- **最新功能**：拖拉調整階層與順序、拖拉時自動平移畫布、依階層套用色塊，以及回收站永久刪除。
- **文件更新日期**：`2026-10-17`。

本文件依目前 `main` 分支的 `index.html` 整理。網站由 GitHub Pages 託管，**作品資料仍儲存在使用者的瀏覽器，並非存放於 GitHub 儲存庫或雲端資料庫**。不同電腦、瀏覽器、瀏覽器設定檔或網站來源，各自使用獨立的本機資料；需要移轉作品時，請使用 JSON 匯出與匯入。

## 1. 開始使用與建立心智圖

### 第一次使用

1. 開啟 [LumiTree 網站](https://samliang0729-alt.github.io/lumitree-web/)。
2. 點選「建立心智圖」、「新建心智圖」，或直接選擇首頁的版型卡片。
3. 選擇適合的圖形結構，建立含範例主題的心智圖。
4. 在上方名稱欄輸入作品名稱。
5. 雙擊中心主題或子主題，修改文字。
6. 選取主題後，使用工具列新增子主題、同層主題，或調整樣式。
7. 編輯內容會自動儲存在目前瀏覽器；可由上方儲存狀態確認。

**作品名稱與中心主題文字為不同欄位**。修改上方作品名稱不會同步改寫中心主題；中心主題文字請另行雙擊編輯。

### 首頁功能

| 功能區塊 | 操作與規則 |
| --- | --- |
| 全部心智圖 | 顯示目前本機工作空間內，尚未移至回收站的作品。 |
| 最近編輯 | 以最近更新時間查看作品；也可切換名稱排序。 |
| 我的收藏 | 點選作品卡片的星號收藏，再由此篩選查看。 |
| 搜尋 | 依作品名稱搜尋，不搜尋各主題內文。 |
| 建立副本 | 複製作品內容，產生獨立的副本。 |
| 範本中心 | 選擇 8 種基本圖形版型；編輯中亦可切換結構。 |
| 從檔案開啟 | 匯入 LumiTree JSON，或帶有縮排的 TXT、MD 文字大綱。 |
| 回收站 | 提供作品還原與確認後永久刪除。 |

## 2. 編輯主題與工具列

### 基本操作

| 操作 | 使用方式 | 說明 |
| --- | --- | --- |
| 選取主題 | 單擊主題 | 右側設定區顯示所選主題的設定。 |
| 修改文字 | 雙擊主題，或按 `F2`、空白鍵 | 輸入完成後按 `Enter`，或離開輸入欄完成編輯；按 `Esc` 取消本次文字編輯。 |
| 新增子主題 | 「子主題」或 `Tab` | 建立所選主題的下一層。 |
| 新增同層主題 | 「同層主題」或 `Enter` | 建立與所選主題相同的父層關係；中心主題不能新增同層。 |
| 刪除主題 | 「刪除」或 `Delete` | 一併移除該主題的所有子層；中心主題不能刪除。 |
| 收合／展開 | 主題旁的 `＋／−`，或工具列按鈕 | 暫時隱藏或顯示子層，不會刪除內容。 |
| 復原 | 「復原」、`Ctrl+Z` | 還原本次編輯工作階段內的主題、階層、版型或樣式調整。 |
| 重做 | 「重做」、`Ctrl+Shift+Z` 或 `Ctrl+Y` | 重新套用剛復原的操作。 |
| 適合畫面 | 「適合畫面」 | 將目前展開的主題調整到畫布可見範圍。 |
| 全螢幕 | 「全螢幕」 | 依瀏覽器支援狀況切換；也可使用瀏覽器的全螢幕操作。 |

快捷鍵於文字輸入、選單操作或對話視窗開啟時，會依目前輸入情境處理。macOS 亦支援以 `Command` 取代 `Ctrl` 的復原／重做組合鍵。

**復原紀錄僅保留於本次開啟作品的編輯工作階段，最多 80 筆**；重新整理或重新開啟作品後會重設。作品名稱變更、首頁收藏、作品移至回收站及永久刪除，不屬於編輯畫面的復原範圍。

## 3. 拖拉調整上下階層與順序

### 改為另一主題的子層

1. 按住要移動的子主題，拖到目標主題的**中央區域**。
2. 目標主題出現綠色外框時，查看畫面提示是否為預期的父層。
3. 放開滑鼠，移動的主題會成為目標主題的子主題。
4. 系統重新排版，並依新的階層自動更新色塊。

### 提升階層或調整同層順序

1. 將主題拖到目標主題的**上緣或下緣**。
2. 出現綠色插入線後，確認畫面提示的放置位置。
3. 放開滑鼠，移動的主題會與目標主題同層，排列於其之前或之後。

| 放置位置 | 結果 |
| --- | --- |
| 目標主題中央 | 成為目標主題的子主題。 |
| 目標主題上緣 | 與目標主題同層，排在其之前。 |
| 目標主題下緣 | 與目標主題同層，排在其之後。 |
| 空白處或無效位置 | 不變更主題的階層關係。 |
| 拖拉時按 `Esc` | 取消本次拖拉。 |

移動時會**連同所有子層一起移動**，不必逐一調整。中心主題不能被拖成其他主題的子層；也不能把主題放到自己的子層內，以免形成循環關係。中心主題僅接受其他主題拖入其子層，不能作為同層插入位置。

同層順序會影響自動排版的位置；在雙向心智圖中，調整順序也可能改變分支分布於左側或右側的位置。

## 4. 拖拉時自動移動畫布

當目標主題位於目前可見範圍之外時，不需要先放開正在拖拉的主題。

1. 按住主題開始拖拉。
2. 將滑鼠停在**畫布內側**的上、下、左或右邊緣。
3. 畫布會持續平移，帶出原本畫面外的主題；越靠近邊緣，移動速度越快。
4. 看到目標後，將滑鼠移回畫布中央區域，再拖到目標主題放開。

| 滑鼠所在位置 | 畫布反應 |
| --- | --- |
| 靠近上邊緣 | 圖面向下移，方便查看更上方的主題。 |
| 靠近下邊緣 | 圖面向上移，方便查看更下方的主題。 |
| 靠近左邊緣 | 圖面向右移，方便查看更左方的主題。 |
| 靠近右邊緣 | 圖面向左移，方便查看更右方的主題。 |
| 回到中央、移出畫布、放開滑鼠或按 `Esc` | 停止自動平移。 |

放置主題後會保留目前縮放比例；必要時僅調整視野，讓移動後的主題仍可看見。若要重新總覽整張圖，請使用「適合畫面」。

未拖拉主題時，可拖曳畫布空白處手動平移；滑鼠滾輪或右下角的 `＋／−` 可調整縮放。

## 5. 階層色塊與右側設定區

### 階層配色規則

採用**同一階層同色、不同階層不同色塊**的方式標示，左右分支只要層級相同，就會使用相同的階層配色。

| 階層 | 預設色塊 | 說明 |
| --- | --- | --- |
| 中心主題 | 深青綠 | 整張心智圖的起點。 |
| 第 1 層 | 淺綠 | 直接連到中心主題。 |
| 第 2 層 | 淺橘粉 | 第 1 層的子主題。 |
| 第 3 層 | 淺紫 | 第 2 層的子主題。 |
| 第 4～6 層 | 淺黃、淺藍、淺粉紫 | 依深度繼續區分。 |
| 更深階層 | 自動產生的淺色塊 | 依階層深度產生配色。 |

以上為初始配色；選擇其他階層配色組合，或自訂本層顏色後，將依設定顯示。拖拉改變階層時，主題及子層會自動套用各自新階層的顏色。

### 設定區分頁

| 分頁 | 可調整內容 |
| --- | --- |
| 樣式 | 主題形狀、寬度、字級、粗體，以及本層填滿色、邊框色、文字色。 |
| 版型 | 切換圖形結構、連線樣式及線條粗細。 |
| 大綱 | 以縮排列出完整主題階層；點選可定位至該主題。 |

**填滿色、邊框色與文字色會套用至同一階層的所有主題**；形狀、寬度、字級與粗體則調整目前選取的主題。「還原本層配色」可回到該階層的自動配色；「重設此主題樣式」用於重設選取主題的個別外觀設定。

預設中心主題為 `22px`，一般主題為 `17px`。右側樣式區可調整字級與主題寬度，並提供階層色塊對照。

## 6. 圖形版型

| 版型 | 適用內容 |
| --- | --- |
| 心智圖 | 自由發想、主題關聯與雙向展開。 |
| 邏輯圖 | 單向展開、層次分析與內容拆解。 |
| 括弧圖 | 分類歸納、知識整理與章節結構。 |
| 組織圖 | 由上而下呈現組織與工作分工。 |
| 樹狀圖 | 階層清單、任務分解與逐層展開。 |
| 時間軸 | 依主題順序呈現階段與里程碑。 |
| 魚骨圖 | 問題與原因分類分析。 |
| 樹型表格 | 以表格色塊整理階層與分類內容。 |

編輯中切換版型會保留主題文字與階層關係，再依新結構重新排版。時間軸依主題順序顯示，並非以日期欄位自動計算的甘特圖。

## 7. 匯入文字大綱與檔案

### 編輯中的文字匯入

1. 點選上方「文字匯入」。
2. 第一行輸入中心主題；每 **2 個空白**或 **1 個 Tab** 表示下一層。
3. 貼上或修改大綱後，點選「產生心智圖」。
4. 系統會取代目前作品的主題內容；需要時可立即使用「復原」還原。

```text
產線改善計畫
  品質改善
    降低不良率
    首件確認
  設備改善
    自主保全
    故障原因分析
  人員訓練
    標準作業
    技能培訓
```

可貼上自行撰寫或由其他工具產生的文字大綱；LumiTree 本身未串接 AI 模型服務。

### 從檔案開啟

| 檔案格式 | 匯入行為 |
| --- | --- |
| `.json` | 讀取 LumiTree 匯出的作品資料，包含主題、階層、版型及樣式。亦支援早期版的主題陣列格式。 |
| `.txt`、`.md` | 依文字縮排解析成主題階層，不會解析成完整 Markdown 文件排版。 |
| `.xmind` | 目前不支援 XMind 專用檔案格式。 |

首頁「從檔案開啟」會建立一份新作品，不會覆蓋同名的既有作品。檔案選擇器目前一次匯入一個檔案。

### 匯入與欄位規則

| 項目 | 規則 |
| --- | --- |
| 檔案大小 | 上限 `5 MiB`，即 `5 × 1024 × 1024` 位元組。 |
| JSON 匯入主題數 | 每份作品需有 `1～1000` 個主題。 |
| 文字大綱 | 需有 `1～1000` 個非空白行。 |
| 中心主題 | 每份作品必須只有一個中心主題。 |
| 主題關係 | ID 不可重複；父主題需存在，且不得形成循環。 |
| 作品名稱 | 最多 `100` 個字元。 |
| 檔案匯入的主題文字 | 每個主題保留最多 `3000` 個字元；單一主題的文字編輯欄亦限制為 `3000` 個字元。 |
| 字體大小 | 樣式設定範圍 `10～36px`。 |
| 主題寬度 | 樣式設定範圍 `100～320px`。 |

## 8. 匯出與備份

點選編輯畫面右上角「匯出」，選擇需要的格式。

| 格式 | 用途與規則 |
| --- | --- |
| JSON 備份 | 保留完整主題資料、版型、樣式及收合狀態；可重新匯入繼續編輯。 |
| SVG 向量圖 | 適合插入文件、簡報或進行放大輸出。 |
| PNG 圖片 | 匯出成一般圖片；大型圖面會限制輸出尺寸，以降低瀏覽器記憶體負擔。 |
| PDF／列印 | 開啟瀏覽器列印功能，在目的地選擇「另存為 PDF」；列印設定依瀏覽器提供的選項操作。 |

**JSON 是可重新編輯的備份格式；SVG、PNG 與 PDF 為圖面輸出。** 圖面輸出依目前展開的主題生成，若需完整展示所有子層，請先展開再匯出。畫布的平移位置與縮放比例，不代表輸出圖面的裁切範圍。

每次 JSON 匯出僅備份目前開啟的一份作品。若要移轉多份作品，請逐份匯出。

## 9. 回收站與永久刪除

### 將作品移至回收站

1. 回到管理首頁。
2. 點選作品卡片的「移至回收站」。
3. 作品將由一般列表移至回收站，仍可還原。

### 還原作品

1. 點選左側「回收站」。
2. 找到要恢復的作品，點選「還原」。
3. 回到「全部心智圖」即可繼續編輯。

### 永久刪除

1. 在回收站點選該作品的「永久刪除」。
2. 確認視窗會顯示作品名稱及刪除影響。
3. 點選「取消」會保留作品；確認「永久刪除」才會移除資料。

**永久刪除後，無法從回收站還原，也無法使用編輯畫面的「復原」救回。** 需要保留內容時，請先還原作品並匯出 JSON 備份。匯出檔仍需由使用者自行保管。

## 10. 本機儲存與資料移轉

| 情況 | 資料行為與建議 |
| --- | --- |
| 同一瀏覽器、同一設定檔及同一網站來源 | 會讀取該工作空間已儲存的作品。 |
| 換電腦、換瀏覽器或換設定檔 | 不會自動帶入原作品；請以 JSON 移轉。 |
| 從 GitHub Pages 改用本機網站 | 網站來源不同，資料不會自動共用。 |
| 清除網站資料或瀏覽器儲存空間 | 可能移除本機作品；請事先備份。 |
| 無痕／私密瀏覽 | 不適合長期保存作品；請於結束前匯出。 |
| 儲存空間不足或寫入失敗 | 留意上方儲存狀態與提示，立即匯出 JSON。 |
| 更新網站程式 | 使用相同網站來源時，會沿用本機工作空間；更新前仍建議備份重要作品。 |

本機儲存使用瀏覽器 `localStorage`。目前未提供帳號權限、多人即時協作、自動雲端備份或跨裝置同步。傳送 JSON 檔可讓他人匯入獨立副本，後續編輯不會彼此同步。

## 11. 本機使用與 GitHub Pages 部署

### 專案結構與技術

| 項目 | 說明 |
| --- | --- |
| `index.html` | 完整前端應用程式，包含 HTML、CSS 與原生 JavaScript。 |
| `README.md` | 功能、操作、儲存及部署說明。 |
| 執行方式 | 靜態網頁，不需要前端套件安裝或建置程序。 |
| 外部依賴 | 目前應用程式不需載入 React、Tailwind、Babel 或外部 PDF 套件。 |
| 資料儲存 | 使用瀏覽器本機儲存，不需設定外部資料庫或 API 金鑰。 |

### 本機使用

可下載 `index.html` 後以瀏覽器開啟。若需要較一致的網站來源與本機儲存行為，建議在檔案所在資料夾啟動靜態 HTTP 伺服器，例如電腦已安裝 Python 時：

```bash
python -m http.server 8000
```

啟動後，以瀏覽器開啟 [http://localhost:8000/](http://localhost:8000/)。不需要另行安裝 Python 套件；`index.html` 應放在執行指令的資料夾內。

直接使用 `file://` 開啟時，本機儲存行為可能因瀏覽器或檔案位置而異。**GitHub Pages、本機 HTTP 網址與直接開啟檔案的工作空間不會自動互通**，請使用 JSON 移轉資料。

### GitHub Pages 維護

1. 在 `main` 分支更新根目錄的 `index.html`。
2. 提交變更後，由儲存庫既有的 GitHub Pages 工作流程發布。
3. 在 GitHub 的 Actions 或 Pages 部署紀錄確認發布結果。
4. 開啟 [網站入口](https://samliang0729-alt.github.io/lumitree-web/)，確認新功能與畫面。
5. 若仍顯示舊畫面，可使用 `Ctrl+Shift+R` 強制重新整理。

重新設定 Pages 時，請在儲存庫 **Settings → Pages** 確認發布來源指向包含 `index.html` 的分支與目錄。保留既有的網站網址與儲存庫存取設定，避免無意間切換使用者的本機工作空間。

## 12. 常見問題

| 問題 | 處理方式 |
| --- | --- |
| 網頁直接顯示程式碼 | 確認上傳的是完整、正確的 `index.html`，且 Pages 部署成功；不要把尚未轉換的 JSX 當成一般 HTML 內容貼入。 |
| 更新後仍是舊畫面 | 確認部署完成，再強制重新整理；不必為了更新畫面清除網站資料。 |

| 關閉後無法使用復原 | 復原紀錄不跨工作階段保存；請使用既有 JSON 備份恢復需要的版本。 |
